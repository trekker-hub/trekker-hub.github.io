# trekker-hub.github.io

Personal site for Tariq Aldalou — computer engineer (FPGA, embedded systems,
formal verification). Live at **https://trekker-hub.github.io**

Plain HTML, CSS and JavaScript. No framework, no build step, no dependencies.

```
content.js     all site content — the only file that normally changes
index.html     homepage frame
project.html   project write-up frame (project.html?id=<project-id>)
app.js         renders content.js into the frames
style.css      design tokens and layout
images/        photos and diagrams
resume.pdf     linked from the résumé buttons
```
